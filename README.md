# 🎮 League of Legends Menu Interface

Una réplica fiel de la interfaz del cliente de League of Legends desarrollada con **HTML5**, **SCSS** y **JavaScript vanilla**.

## 🌟 Características

### 🎨 Interfaz Auténtica
- **Diseño pixel-perfect** que replica la interfaz oficial de LoL
- **Animaciones suaves** y efectos visuales inmersivos
- **Video de fondo** con creado por diseñador grafico externo
- **Efectos de glassmorphism** en la barra de navegación

### ⚡ Funcionalidades Interactivas
- **Sistema de navegación** dinámico con selección de juegos (LoL, TFT, LoR)
- **Perfil de usuario** completo con:
  - Sistema de experiencia circular animado
  - Estados en línea personalizables
  - Tooltips informativos flotantes
  - Slider de experiencia con controles
- **Panel social** con lista de amigos
- **Notificaciones** interactivas

### 🎯 Efectos Visuales
- **Efectos de hover** con destellos luminosos
- **Bordes brillantes** con gradientes celestes
- **Clip-path** para formas hexagonales y personalizadas
- **Transiciones suaves** en todos los elementos

## 🛠️ Tecnologías Utilizadas

- **HTML5** - Estructura semántica
- **SCSS/Sass** - Estilos avanzados con variables y funciones
- **JavaScript ES6+** - Lógica interactiva
- **CSS Grid & Flexbox** - Layout responsivo
- **FontAwesome** - Iconografía


## 🎨 Personalización

### Variables de Color (SCSS)
```scss
$primary-color: #3fe3f8;    // Celeste principal
$secondary-color: #00575e;   // Celeste oscuro
$dark-bg: #08101D;          // Fondo oscuro
$color-borde: #7a5400;      // Dorado para bordes
$light-text: #fff1b4;       // Texto claro
```

### Configuración de Usuario
```javascript
const Usuario = {
    nombre: "Tu Nombre",
    nivel: 30,
    experiencia: 75,
    icono: "./assets/tu-icono.jpg",
    skinFavorita: "./assets/tu-skin.jpg"
};
```

## 📱 Responsividad

- **Desktop First** - Optimizado para pantallas de escritorio
- **Elementos fijos** que mantienen proporciones
- **Overflow controlado** en el panel lateral

## 🐛 Problemas Conocidos

- El video de fondo puede tardar en cargar en conexiones lentas
- Algunos efectos CSS pueden no ser compatibles con navegadores muy antiguos
- Los tooltips requieren JavaScript habilitado
